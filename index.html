FORMAL DEFINITION

DPDA as a 7-Tuple

M = (Q, Σ, Γ, δ, q₀, Z₀, F)

  • Q → Finite set of states
  • Σ → Input alphabet
  • Γ → Stack alphabet
  • δ → Transition function
  • q₀ → Initial state
  • Z₀ → Initial stack symbol
  • F → Set of final states
DETERMINISM RULE

Why is it a DPDA?

A deterministic PDA must have only one possible transition for a given combination of current state, input symbol and stack top.

δ : Q × (Σ ∪ {ε}) × Γ → Q × Γ*

The simulator checks for duplicate transitions and conflicts between ε-transitions and input-consuming transitions.
